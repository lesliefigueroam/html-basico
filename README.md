# Cómo hacer que te pasen cosas buenas – Marian Rojas Estapé

Proyecto web desarrollado como actividad práctica del curso de Desarrollo Web.

## Descripción

Página web informativa sobre el libro _Cómo hacer que te pasen cosas buenas_ de la psiquiatra española Marian Rojas Estapé. El sitio presenta los conceptos principales del libro, incluyendo el manejo del estrés, el propósito de vida y la gestión emocional.

## Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries)
- Bootstrap 5.3.3
- JavaScript

## Funcionalidades

- Diseño responsivo con enfoque **Mobile First**
- Barra de navegación con menú hamburguesa (Bootstrap)
- Adaptación a móvil, tablet y escritorio mediante **Media Queries**
- Se agregó el archivo `app.js` con la funcionalidad de scroll suave
